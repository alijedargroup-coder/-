# دليل نشر نموذج مجمع OCR مجاناً (Render / Railway)

هذا الدليل يشرح كيف تنشر البوت برابط عام مجاني يفتحه أي شخص (مثل المدير) من أي جهاز.

## الخطوة 1: احصل على مفتاح Google Gemini API (مجاني بالكامل)
1. روح لـ https://aistudio.google.com وسجل دخول بحساب Google عادي.
2. اضغط "Get API key" ثم "Create API key".
3. انسخ المفتاح (يبدأ بـ `AIza...`).
4. لا يحتاج أي بطاقة ائتمان، وله حد استخدام يومي مجاني كريم يكفي هذا النموذج التجريبي بسهولة.

## الخطوة 2: ارفع الكود على GitHub
1. سوي حساب مجاني على https://github.com إذا ما عندك.
2. أنشئ مستودع (repository) جديد فارغ، وارفع له كل الملفات الموجودة بهذا المجلد (`server.js`, `package.json`, `public/`).

## الخطوة 3: انشر على Render (مجاني)
1. روح لـ https://render.com وسجل حساب مجاني (تكدر تسجل مباشرة بحساب GitHub).
2. اضغط "New +" ثم "Web Service".
3. اختر المستودع اللي رفعته بالخطوة 2.
4. اترك الإعدادات الافتراضية، بس تأكد:
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: **Free**
5. بقسم "Environment Variables" ضيف متغير:
   - Key: `GEMINI_API_KEY`
   - Value: المفتاح اللي نسخته بالخطوة 1
6. اضغط "Create Web Service" وانتظر دقيقتين لين يخلص النشر.

## الخطوة 4: جرب الرابط
Render راح يعطيك رابط شكله تقريباً:
`https://ocr-chat-demo.onrender.com`

هذا الرابط تكدر ترسله مباشرة للمدير، يفتحه بأي متصفح عادي (موبايل أو كمبيوتر) بدون أي إعداد إضافي من طرفه.

## ملاحظة عن الخطة المجانية
خطة Render المجانية "تنام" السيرفر إذا ما استخدم لمدة، فأول رسالة بعد فترة توقف تاخذ 20-30 ثانية إضافية لين يصحى السيرفر، وبعدها يرجع سريع طبيعي. إذا هذا مزعج للعرض على المدير، أرسل له أول رسالة بنفسك قبل لا يفتحها بدقيقة حتى يصحى السيرفر.
